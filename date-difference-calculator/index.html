Days Between Dates

Count the days — and working days — between any two dates.

How the days are counted

By default we count the days between the dates — from the start of the first date to the start of the last. From Monday to Friday is 4 days. Tick "include the end date" to count both ends (5 days), which is how many people count holidays or project durations.

Working days

Working days are Monday to Friday. Public holidays differ by country and region, so they aren't removed — subtract any that fall in your range.

Frequently asked questions

Does it handle leap years and daylight saving?

Yes. Dates are calculated in UTC so clock changes never add or lose a day, and 29 February is counted in leap years.

Can I count down to an event?

Yes — set the start date to today and the end date to your event.
